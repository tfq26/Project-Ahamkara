Ahamkara

A custom C++20 game engine and multiplayer tech demo built from scratch.

Dedicated authoritative server with client networking skeleton — UDP transport at ~60 Hz, GLFW3 debug renderer, CMake + Ninja build.

Explore the Engine View Source

Philosophy

Ahamkara is a reusable C++20 game engine and multiplayer tech demo built from the ground up — no middleware, no shortcuts.

The engine provides the foundational systems needed to build modern networked games: core utilities, a dedicated authoritative server, real-time networking, 3D rendering, physics and collision, animation, audio, and a platform abstraction layer. Designed for determinism, low latency, and developer control.

Wish

Wish is an independent backend and session platform that powers the live-service layer for games built with Ahamkara.

It owns identity, authentication, admission, sessions, activities, replication envelopes, administration, and backend integrations — all independent from the game engine, so any game can use it.

Inspiration

Built by one developer, inspired by the best in the industry.

  • Destiny — moment-to-moment gameplay feel, seamless netcode, and immersive world-building.
  • Call of Duty — the gold standard for arcade FPS: tight gunplay, snappy movement, and satisfying game feel.
  • Engine development — data-oriented design, deterministic networking, and systems-level engineering in modern C++20.
