Engine

What is Ahamkara?

Ahamkara is a reusable C++20 game engine built from the ground up — no middleware, no shortcuts.

It provides a complete runtime host, SDK, rendering pipeline, animation system, physics and collision, audio, netcode with lag compensation, and a full toolchain. Designed for determinism, low latency, and developer control.

  • Core: Entity-component system, diagnostics, math, platform abstraction
  • Network: UDP transport, snapshot interpolation, reliable channels, lag-compensated hit validation
  • Render: PBR pipeline, animation blending, level-driven environments
  • AI: 6 combatant archetypes, state-machine behaviors, spatial navigation

Platform

What is Wish?

Wish is an independent backend and session platform that powers the live-service layer.

It owns identity, authentication, admission, sessions, activities, replication envelopes, administration, and backend integrations — all independent from the game engine, so any game can use it.

  • Identity: Player accounts, authentication, profile management
  • Sessions: Match lifecycle, player admission, state replication
  • Activities: Game-neutral activity routing and server-authoritative tick
  • Integrations: Nakama adapter, extensible service architecture
