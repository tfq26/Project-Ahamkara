Project Overview

What is Ahamkara?

Ahamkara is a reusable game engine, runtime host, and SDK written in modern C++20. It provides the foundational layers — core utilities, networking, collision, physics, rendering, animation, input, audio, and UI — that game projects need to ship.

Platform

Introducing Wish

Wish is an independent backend, session, and activity platform with a game-neutral protocol. It handles matchmaking, parties, persistence, rewards, and live-content hooks — so your game logic stays clean and portable.
