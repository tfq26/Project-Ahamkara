# Ahamkara Valgrind Suppression File
# ===================================
#
# Suppressions for known false positives in third-party dependencies
# and platform libraries. Add project-specific suppressions above the
# marker line.
#
# Usage:
#   valgrind --suppressions=scripts/valgrind-suppressions.txt <test_binary>
#
# See also: scripts/valgrind-tests.sh
#
# WARNING: Suppressions hide real leaks. Only add entries here after
# confirming the leak originates from code OUTSIDE this project's
# control and does NOT indicate a bug in our usage of that library.

# ---------------------------------------------------------------
# Project-specific suppressions — add entries above this section
# ---------------------------------------------------------------

# ---------------------------------------------------------------
# Third-party library suppressions
# ---------------------------------------------------------------

# JoltPhysics internal allocations
# Jolt maintains internal caches and pools that are intentionally
# never freed during normal process lifetime.
{
   <jolt-physics-persistent-allocations>
   Memcheck:Leak
   match-leak-kinds: reachable,possibly-lost
   fun:malloc
   ...
   obj:*Jolt*
}

# GLM detail/internal allocations (header-only math library)
# GLM may perform small internal allocations for static data.

   Memcheck:Leak

   fun:malloc
   ...
   obj:*glm*
}
