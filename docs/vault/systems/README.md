# System Maps

Use this folder for human and agent-readable maps of important subsystems.

## Maps

- [[systems/build-and-test-map]]

- [[systems/rendering-map]]

- [[systems/asset-pipeline-map]]

System maps should answer:

- what this subsystem owns
- what it depends on
- where the main files live
- which tests verify it
- what future agents should avoid assuming

Keep system maps compact and link to source files or canonical docs for detail.
