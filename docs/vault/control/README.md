# Agent Control

This folder is for user-visible steering controls when Ahamkara uses a
multi-agent workflow.

Suggested files:

- `user-directives.md` - standing priorities and instructions
- `stop-requests.md` - requests to halt a task, agent, or group
- `steering-requests.md` - requested changes in direction or priority

Create those files when a supervised multi-agent run actually needs them.
