# Blocked Tasks

OpenCode places tasks here when it cannot continue without user or Codex input.

Blocked tasks should link to a report that explains the blocker and the next
decision needed.

## Deferred Tasks

Some blocked tasks are intentionally deferred until the user says the project
is in a working state again. Keep those out of active queue work until that
explicit resume signal arrives.
